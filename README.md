12주차 AI 프로그래밍 실습 프로젝트입니다. pandas를 사용해 학생 점수 CSV를 정제하고, 반과 과목별로 필터링·그룹화·통계를 내며, pytest로 결과를 확인합니다.

## 무엇을

- `scores_2026.csv`의 점수 결측 행, 완전 중복 행, 점수 범위 밖 행을 처리합니다.
- 반과 과목 이름의 앞뒤 공백을 제거합니다.
- 정제된 데이터에서 반별·과목별 점수 평균과 반별 통계를 계산합니다.
- 테스트 파일에서 정제 결과와 집계값을 검증합니다.

## 어떻게

`analysis.py`의 `정제(df)` 함수는 다음 순서로 처리합니다.

1. 점수가 비어 있는 행을 삭제합니다.
2. 모든 열이 같은 중복 행을 제거합니다.
3. 반과 과목 값의 앞뒤 공백을 제거합니다.
4. 점수가 0~100 범위를 벗어난 행을 제거합니다.

이후 pandas의 필터링과 `groupby`를 사용해 평균, 중앙값, 최댓값 등을 계산합니다. `test_analysis.py`는 정제 후 행 수, 반 종류, 점수 합계, `mini.csv`의 1반 평균을 확인합니다.

## 왜

CSV 데이터의 정제와 분석 과정을 익히고, 자동화된 테스트로 코드 결과가 명세와 일치하는지 확인하기 위한 수업 실습입니다. CSV 데이터는 연습용 예시입니다.

## 실행 방법

프로젝트 폴더에서 가상환경을 활성화한 뒤 실행합니다.

```powershell
python analysis.py
python -m pytest -q test_analysis.py
```

필요한 패키지는 `pandas`와 `pytest`입니다.

## 주요 파일

- `analysis.py`: CSV 정제, 필터링, 그룹화 및 통계 코드
- `test_analysis.py`: pytest 테스트와 직접 실행 시 테스트 결과 출력
- `scores_2026.csv`: 기본 연습 데이터
- `scores_2026_cp949.csv`: CP949 인코딩 연습 데이터
- `mini.csv`: 손계산과 테스트를 위한 작은 예시 데이터
- `prompts.txt`: 실습 단계별 프롬프트 원문
